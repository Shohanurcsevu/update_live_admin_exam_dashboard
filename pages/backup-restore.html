How backups work

  • Backups are versioned JSON files — open them in any text editor.
  • The file includes all 15 data tables from your account.
  • Skip mode is always safe to run — it won't touch existing data.
  • Overwrite mode replaces records by ID — use only when migrating or resetting.
  • Always download a fresh backup before importing to ensure nothing is lost.
