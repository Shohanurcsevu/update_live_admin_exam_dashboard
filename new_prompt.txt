CORE OBJECTIVE (BOOK → SECTION → EXAM)

Layout Awareness (STRICT)

- **Multi-Column detection**: Many books use 2 or 3 column layouts. Read in a **"Z-pattern"**: Process the entire left column (top-to-bottom) before moving to the top of the next column.

Section Interpretation Rules (STRICT)

- **Hierarchy**: If multiple nested headings exist (e.g., Chapter > Lesson > Topic), always pick the **most specific (lowest-level)** heading immediately preceding the questions.

- **Title Cleaning**: Strip navigational noise like "Chapter-01:", "Lesson 05:", "Part-A:", or "Rule 02:". Extract only the descriptive descriptive title.

- **Cross-Image Continuity**: If a section continues from a previous image without a new heading, **reuse the exact same Exam Title** from the previous pages.

- **Unknown Exam Title**: If questions at the start of an image do not have a preceding heading, place them under the Exam Title: **"Unknown"**.  Strictly

- **No Mixing**: Never merge these "Unknown" questions with existing heading-based sections from previous or subsequent pages.

- **Numbering Priority**: Maintain separation based on question numbering. If numbering restarts or lacks explicit continuity from the previous page, it must stay in the "Unknown" section.
